# AI Day Planner — Jac Tutorial

Working through the **Build an AI Day Planner with Jac** tutorial:
https://docs.jaseci.org/tutorials/first-app/build-ai-day-planner/

Each part of the tutorial lives in its own folder and is committed separately.

## Parts

1. [`part1/`](part1/) — Your First Lines of Jac (syntax, types, functions, `obj`)
2. [`part2/`](part2/) — Modeling Data with Nodes (`node`, `root`, `++>`, filter comprehensions)
3. `part3/` — Building the Backend API _(upcoming)_
4. `part4/` — A Reactive Frontend _(upcoming)_
5. `part5/` — Making It Smart with AI _(upcoming)_
6. `part6/` — Authentication & Multi-File Organization _(upcoming)_
7. `part7/` — Object-Spatial Programming with Walkers _(upcoming)_

## Running

```sh
jac <file>.jac          # run a script
jac start main.jac      # start the web server (parts 3+)
```

Jac 0.14.0 with plugins: `byllm`, `jac-client`, `jac-scale`.
